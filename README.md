## About

I develop and operate production mobile and backend systems with a focus on
clear contracts, predictable behavior, and maintainable delivery. My current
work centers on real-time social products, live-streaming flows, media
pipelines, account safety, and transactional wallet operations.

Most of my production work is maintained in private organization repositories.
Public activity therefore represents only part of my day-to-day engineering
work.

## Engineering Focus

- Designing mobile and backend changes as one end-to-end contract
- Building resilient real-time flows for live sessions and audience state
- Protecting wallet, purchase, and entitlement operations with server authority
- Improving media upload, moderation, and playback pipelines
- Separating staging and production configuration with traceable releases
- Adding focused tests, operational logs, and rollback-aware deployment steps

## Working Principles

1. Understand the existing system and production behavior before changing it.
2. Keep ownership of critical state explicit across mobile, backend, and third-party services.
3. Test the failure paths that affect users, balances, live sessions, and releases.
4. Prefer small, reviewable changes with clear commit history and deployment notes.
