## Professional Profile

I develop mobile, backend, and web products from initial requirements through
release and production operation. My work combines cross-platform application
development, API and data design, real-time communication, media processing,
payment flows, third-party integrations, and deployment automation.

I am most effective on features that cross system boundaries: defining the
backend contract, implementing the client experience, handling failure cases,
testing the complete flow, and preparing a traceable release.

## Working Principles

1. Understand current production behavior before changing it.
2. Keep critical state and financial operations authoritative on the server.
3. Treat mobile, backend, and third-party services as one end-to-end contract.
4. Test failure paths as carefully as successful flows.
5. Keep changes reviewable, releases traceable, and rollback paths clear.
