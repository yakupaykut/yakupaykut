## Engineering Principles

1. Understand current production behavior before changing it.
2. Keep financial and critical state authoritative on the server.
3. Treat mobile, backend, and third-party services as one end-to-end contract.
4. Test failure paths and rollback conditions before release.

Most production work is maintained in private repositories. The public projects
above isolate reusable engineering patterns without exposing proprietary code,
credentials, infrastructure details, or internal product documentation.
